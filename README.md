# Telegram Бот для стоматологии

Интеллектуальный Telegram бот для записи пациентов в стоматологическую клинику с интеграцией Google Calendar и AI-консультантом.

## 📋 Основные возможности

### 📅 Умная система записи
- Выбор процедуры с ценами из конфига
- Автоматический поиск свободных окон в Google Calendar
- Выбор только из доступных временных слотов
- Создание событий в календаре
- Fallback-режим при недоступности календаря

### 💬 AI-консультант (VSellm)
- Ответы на вопросы пациентов
- Настраиваемый системный промпт
- Автоматическая вставка прайса
- Предложение записи после консультации

### 👨‍⚕️ Админские функции
- Уведомления о новых записях
- Статистика записей (/stats)
- Мониторинг ошибок

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env` и заполните:
```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_CHAT_ID=123456789

AI_API_KEY=your_vsellm_api_key_here
AI_BASE_URL=https://api.vsellm.com/v1
AI_MODEL=vsellm

GOOGLE_CALENDAR_ID=your_calendar_id@group.calendar.google.com
GOOGLE_SERVICE_ACCOUNT_JSON=base64_encoded_service_account_json_here
```

### 3. Настройка Google Calendar
Следуйте инструкции в [SETUP_GOOGLE.md](SETUP_GOOGLE.md)

### 4. Запуск бота
```bash
npm start
```

Для разработки с автоматической перезагрузкой:
```bash
npm run dev
```

## 🔄 Workflow записи

1. **Пациент**: Нажимает "📅 Записаться"
2. **Бот**: Предлагает процедуры с ценами (из procedures.json)
3. **Пациент**: Выбирает процедуру
4. **Бот**: Предлагает даты (Сегодня, Завтра...)
5. **Бот**: Запрашивает Google Calendar → получает свободные окна
6. **Пациент**: Выбирает из доступных временных слотов
7. **Бот**: Запрашивает имя и телефон
8. **Бот**: Создаёт событие в Google Calendar
9. **Админ**: Получает уведомление о новой записи
10. **Пациент**: Получает подтверждение

## 🛡️ Обработка ошибок и Fallback

### Google Calendar недоступен:
- Бот предлагает оставить телефон
- Админ получает уведомление с контактом
- Пациент не теряется

### AI сервис недоступен:
- Ограниченный режим консультаций
- Предложение записи через кнопку

### Общие ошибки:
- Try/catch во всех обработчиках
- Логирование в консоль
- Уведомления администратору
- User-friendly сообщения для пациентов

## 📊 Админские команды

### `/stats`
Показывает статистику:
- Записи за сегодня
- Записи за неделю
- Оборот за неделю

## 🔧 Технические детали

### Зависимости
- `telegraf`: Telegram Bot API
- `googleapis`: Google Calendar API
- `node-fetch`: HTTP запросы к AI API
- `dotenv`: Управление переменными окружения

### Требования
- Node.js >= 14
- Telegram Bot Token
- Google Service Account
- VSellm API Key (или совместимый OpenAI endpoint)

## 📝 Кастомизация
